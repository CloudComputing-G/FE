4. 주요 사용 흐름
교사 흐름
로그인: 교사가 앱을 열고 로그인 → Cognito가 role=TEACHER JWT 발급 → 교사 대시보드 진입
과제 생성: 'Assignment CRUD' 화면에서 문항별 정답과 채점기준 입력 → POST /assignments → RDS 저장 → 게시(publish)
결과 대기: 학생들이 풀이를 업로드하면 채점 완료 시 SNS → APNs/FCM을 통해 Push 알림 수신
전체 결과 조회: 과제 탭 → GET .../leaderboard → 전체 학생 점수·제출 상태 한눈에 확인
학생 상세 조회: 특정 학생 행 탭 → GET .../students/{uid} → 문항별 이미지와 채점 결과·Claude 판단 근거 카드 확인
재채점 요청: 결과가 잘못된 경우 '재채점' 탭 → POST .../regrade → Lambda가 이전 결과 포함하여 재실행 → 완료 후 카드 업데이트
학생 흐름
로그인: 학생이 앱을 열고 로그인 → Cognito가 role=STUDENT JWT 발급 → 내 과제 목록 진입
풀이 업로드: 과제 탭 → '업로드' 탭 → 사진 선택 → 앱이 Presigned URL 요청 → S3 직접 업로드 → 완료 확인 전송 → Lambda 비동기 호출 → 앱에 '채점 중' 표시
결과 수신: Lambda 완료 → SNS Push 알림 → 앱 진입 → GET .../results → 문항별 채점 결과 카드 확인
오답노트 열람: 오답 카드 탭 → GET /wrong-notes/{id} → 정답·풀이과정·유사 연습문제 확인
AI 튜터 질의: 문항 카드에서 'AI에게 질문' 탭 → POST .../chat → 해당 문항 정답·풀이 주입된 챗봇과 실시간 대화
재채점 요청: 결과 오류 또는 오답 해결 시 → POST .../regrade → 동일한 비동기 재채점 흐름
취약 문제 확인: 여러 제출 누적 후 GET /students/me/weak-points → 틀릴 가능성 높은 문제 목록으로 집중 학습


Appendix] Detailed Implementation Spec
Module Name: Auth Module 
aa. signUp(String email, String password, String role, String name) : AuthResponse 
신규 사용자(교사 또는 학생)를 등록한다. AWS Cognito에 계정을 생성하고, role(TEACHER/STUDENT) 및 사용자 정보를 저장한다. 등록 성공 시 사용자 ID와 역할 정보를 반환한다. 
HTTP Method : POST URL : /auth/signup Request Body : { "email": "user@example.com", "password": "...", "role": "TEACHER", "name": "홍길동" } Response (Success) : HTTP 201 Created / { "userId": "abc123", "role": "TEACHER", "email": "user@example.com" } 
 
ab. login(String email, String password) : TokenResponse 
이메일과 비밀번호로 로그인한다. AWS Cognito를 통해 자격증명을 검증하고, role 클레임(TEACHER/STUDENT)이 포함된 JWT Access Token과 Refresh Token을 발급하여 반환한다. 
HTTP Method : POST URL : /auth/login Request Body : { "email": "user@example.com", "password": "..." } Response (Success) : HTTP 200 OK / { "accessToken": "eyJ...", "refreshToken": "eyJ...", "role": "TEACHER" } 
 
ac. refreshToken(String refreshToken) : TokenResponse 
만료된 Access Token을 갱신한다. 유효한 Refresh Token을 검증하여 새로운 Access Token을 발급한다. Refresh Token이 유효하지 않거나 만료된 경우 401 에러를 반환한다. 
HTTP Method : POST URL : /auth/refresh Request Body : { "refreshToken": "eyJ..." } Response (Success) : HTTP 200 OK / { "accessToken": "eyJ..." } 
 
Module Name: Assignment Module 
ba. createAssignment(String title, List<Question> questions, String teacherId) : AssignmentResponse 
교사가 새 과제를 생성한다. 문항별 정답과 채점기준(부분점수 규칙 포함)을 함께 입력받아 RDS에 저장한다. 
HTTP Method : POST URL : /assignments Request Body : { "title": "3월 모의고사", "questions": [{ "content": "...", "answer": "...", "gradingCriteria": "..." }] } Response (Success) : HTTP 201 Created / { "assignmentId": 1, "title": "3월 모의고사", "status": "DRAFT" } 
 
bb. getAssignments(String teacherId) : List<AssignmentResponse> 
교사가 자신이 생성한 과제 목록을 조회한다. JWT 토큰에서 teacherId를 추출하여 해당 교사의 과제만 반환한다. 
HTTP Method : GET URL : /assignments Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "assignments": [{ "assignmentId": 1, "title": "3월 모의고사", "status": "PUBLISHED" }, ...] } 
 
bc. getAssignment(Long assignmentId) : AssignmentResponse 
특정 과제의 상세 정보를 조회한다. 문항별 정답 및 채점기준 포함하여 반환한다. 
HTTP Method : GET URL : /assignments/{id} Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "assignmentId": 1, "title": "3월 모의고사", "questions": [...] } 
 
bd. updateAssignment(Long assignmentId, AssignmentUpdateRequest request) : AssignmentResponse 
기존 과제의 제목 또는 문항 정보를 수정한다. DRAFT 상태인 과제만 수정 가능하다. 
HTTP Method : PUT URL : /assignments/{id} Request Body : { "title": "3월 모의고사 수정본", "questions": [...] } Response (Success) : HTTP 200 OK / { "assignmentId": 1, "title": "3월 모의고사 수정본" } 
 
be. deleteAssignment(Long assignmentId) : void 
특정 과제를 삭제한다. 교사 본인이 생성한 과제만 삭제 가능하며, 삭제 시 연관된 문항 데이터도 함께 제거된다. 
HTTP Method : DELETE URL : /assignments/{id} Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 204 No Content 
 
bf. updateQuestion(Long assignmentId, Long questionId, QuestionUpdateRequest request) : QuestionResponse 
특정 문항의 정답 및 채점기준을 수정한다. 부분점수 규칙 등 세부 채점 가이드라인을 업데이트한다. 
HTTP Method : PUT URL : /assignments/{id}/questions/{qid} Request Body : { "answer": "x=3", "gradingCriteria": "풀이과정 포함 시 부분점수 2점" } Response (Success) : HTTP 200 OK / { "questionId": 1, "answer": "x=3", "gradingCriteria": "..." } 
 
bg. publishAssignment(Long assignmentId) : AssignmentResponse 
과제를 학생에게 공개한다. DRAFT 상태의 과제를 PUBLISHED 상태로 변경하여 학생 과제 목록에 노출된다. 
HTTP Method : POST URL : /assignments/{id}/publish Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "assignmentId": 1, "status": "PUBLISHED" }

ca. getUploadUrl(Long assignmentId, String studentId) : PresignedUrlResponse 
학생이 풀이 이미지를 S3에 직접 업로드할 수 있도록 Presigned PUT URL을 발급한다. 제출 ID를 함께 생성하여 반환한다. 
HTTP Method : POST URL : /assignments/{id}/submissions/upload-url Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "submissionId": 10, "presignedUrl": "https://s3.amazonaws.com/...", "s3Key": "submissions/10/image.jpg" }

학생이 S3 업로드 완료 후 서버에 확인 신호를 전송한다. 서버는 S3 키와 업로드 상태를 기록하고 GradingService에 채점 Job 생성을 트리거한다. 
HTTP Method : POST URL : /assignments/{id}/submissions/{sid}/confirm Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 202 Accepted / { "submissionId": 10, "status": "PENDING" } 
Module Name: Grading Module 
da. getGradingResult(Long submissionId) : GradingResultResponse 
제출물의 전체 채점 결과를 반환한다. 문항별 정답 여부, 획득 점수, Claude의 판단 근거를 포함하여 반환한다. 
HTTP Method : GET URL : /submissions/{sid}/results Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "submissionId": 10, "totalScore": 85, "questions": [{ "questionId": 1, "isCorrect": true, "score": 10, "reason": "..." }] } 
 
db. getGradingStatus(Long submissionId) : GradingStatusResponse 
채점 Job의 현재 상태를 조회한다. 앱이 채점 완료 여부를 폴링할 때 사용하며 Redis에서 빠르게 읽어 반환한다. 
HTTP Method : GET URL : /submissions/{sid}/results/status Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "submissionId": 10, "status": "IN_PROGRESS" } 
 
dc. requestRegrade(Long submissionId, Long questionId) : RegradeResponse 
특정 문항에 대해 재채점을 요청한다. 이전 채점 결과를 포함하여 Lambda를 비동기 재호출하고, Claude가 이전 판단의 오류 여부를 재검토한다. 
HTTP Method : POST URL : /submissions/{sid}/questions/{qid}/regrade Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 202 Accepted / { "submissionId": 10, "questionId": 1, "status": "PENDING" } 
 
dd. getLeaderboard(Long assignmentId) : LeaderboardResponse 
교사 뷰에서 전체 학생의 총점 및 제출 상태를 조회한다. 정렬 및 필터 기능을 지원한다. 
HTTP Method : GET URL : /assignments/{id}/leaderboard Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "assignmentId": 1, "students": [{ "studentId": "s1", "name": "김철수", "totalScore": 90, "status": "DONE" }, ...] } 
 
de. getStudentResult(Long assignmentId, String studentId) : StudentResultResponse 
교사 뷰에서 특정 학생의 문항별 채점 결과를 상세 조회한다. 풀이 이미지와 Claude의 판단 근거 카드를 함께 반환한다. 
HTTP Method : GET URL : /assignments/{id}/students/{uid} Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "studentId": "s1", "questions": [{ "questionId": 1, "imageUrl": "...", "isCorrect": false, "reason": "..." }] } 
 
Module Name: Review Module 
ea. getWrongNotes(String studentId) : List<WrongNoteResponse> 
학생의 오답노트 전체 목록을 조회한다. 오답 문항을 자동 수집하여 문항 이미지, 정답, 풀이과정을 묶어 반환한다. 
HTTP Method : GET URL : /students/me/wrong-notes Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "wrongNotes": [{ "wrongNoteId": 1, "questionId": 2, "assignmentTitle": "3월 모의고사" }, ...] }

특정 오답노트의 상세 내용을 조회한다. 문항 이미지, 정답, 풀이과정, 유사 연습문제를 함께 반환한다. 
HTTP Method : GET URL : /wrong-notes/{id} Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "wrongNoteId": 1, "questionContent": "...", "answer": "x=3", "imageUrl": "...", "similarProblems": [...] }

오답 문항을 기반으로 유사 연습문제를 생성한다. Review 모듈이 원본 문항을 컨텍스트로 포함하여 AWS Bedrock을 동기 호출하고 생성된 문제를 반환한다. 
HTTP Method : POST URL : /questions/{qid}/similar-problem Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "questionId": 2, "similarProblem": "다음을 풀어라 ...", "answer": "x=5" } 
 
ed. sendChatMessage(Long questionId, String message) : ChatResponse 
학생이 특정 문항에 대해 AI 챗봇에 질문을 전송한다. 해당 문항의 정답 및 풀이과정이 시스템 프롬프트에 주입된 상태로 Bedrock을 호출하여 스트리밍 응답을 반환한다. 
HTTP Method : POST URL : /questions/{qid}/chat Request Body : { "message": "이 문제 풀이과정을 설명해줘" } Response (Success) : HTTP 200 OK / { "answer": "이 문제는 ..." } 
 
ee. getChatHistory(Long questionId) : List<ChatMessageResponse> 
특정 문항의 AI 챗봇 대화 이력을 조회한다. 이전 질문과 응답 목록을 순서대로 반환한다. 
HTTP Method : GET URL : /questions/{qid}/chat/history Request Header : Authorization: Bearer {accessToken} Response (Success) : HTTP 200 OK / { "history": [{ "role": "student", "message": "..." }, { "role": "ai", "message": "..." }] }
